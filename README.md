## Now

**FluxCode**, a lightweight native code editor in Rust, drawn by the GPU.
Windows, macOS and Linux, with an AI agent panel, a Python-friendly
terminal and built-in git. No telemetry. It opens its window in 0.22 s
and sits at 1.4 MB idle, measured on one Windows 11 PC against Zed and
VS Code. [MuaraAI/FluxCode](https://github.com/MuaraAI/FluxCode)

**HideMent**, a browser extension that detects and hides gambling,
phishing and toxic comments in Indonesian on YouTube, Instagram, TikTok
and X. [MyKineID/HideMent](https://github.com/MyKineID/HideMent)

**kiwstudio**, my SaaS website, home of KiwEssentials, a Minecraft
Bedrock essentials add-on. [kiwstudio.com](https://kiwstudio.com)
